# 📱 How to Run on Mobile & Go Live

I have created a **[PRODUCTION_GUIDE.md](./PRODUCTION_GUIDE.md)** with full technical details.

## Quick Mobile Setup (PWA)
1.  Connect phone to same Wi-Fi as PC.
2.  Open browser on phone and go to: **`http://192.168.0.169:3000`**
3.  **Install App**: Tap "Add to Home Screen" in your browser menu.

## Database & Real Apps
To make this a real business app:
1.  **Database**: Connect to **Supabase** (see the Guide).
2.  **Merchant App**: You need to build a separate dashboard for shop owners.
3.  **Login**: Add **Clerk** Authentication.

**Check `PRODUCTION_GUIDE.md` for the step-by-step tutorial!**
